# "Under the Canopy: A Methodological Comparison for Computational Motif Analysis in Nineteenth-Century Painting"

A computational analysis containing object detection analysis used for a paper submitted to CHR conference 2027.

---

## What this project does

Using a corpus of digitised paintings and an automated tree-detection pipeline (SAM3 segmentation), this project investigates:

- **Detection rates** — how frequently trees appear in paintings across time, nationality, and artist
- **Diachronic trends** — how tree prevalence shifts decade by decade and year by year
- **Spatial distribution** — where trees tend to be placed within the canvas
- **Colour analysis** — whether tree pixels are systematically darker, greener, or more saturated than the surrounding canvas

---

## Data

The dataset is publicly available on HuggingFace:

> **[chcaa/CHR\_detection\_trees](https://huggingface.co/datasets/chcaa/CHR_detection_trees)**

It contains one row per painting with image bytes, SAM3 segmentation masks, bounding boxes, and metadata. The notebook loads it automatically:

```python
from datasets import load_dataset
df = load_dataset("chcaa/CHR_detection_trees", split="train").to_pandas()
```

If HuggingFace is unavailable, the notebook falls back to a local file at the project root if downloaded.

## Running the notebook

1. Install the requirements above.
2. Open `CHREADH.ipynb` in Jupyter.
3. Run cells top to bottom. Data loads automatically from HuggingFace. The notebook creates a `figures/` directory and saves all plots as PDFs.

> Cells in sections 2, 8, and 9 read mask data and can be slow on the full corpus (~2,900 paintings).

## Reproducibility

All random sampling uses fixed seeds (`random_state=42` or `random_state=99`). Figures are saved at 300 dpi as PDFs.
